# Road Accident Analysis Dashboard | Excel

## Project Overview
This project is an Excel-based Road Accident Analysis Dashboard developed to analyze road accident casualty data for 2020 and 2021. It presents key metrics, comparisons, and trends through interactive visualizations to make the data easier to understand.

## Objectives
- Analyze road accident casualty data for 2020 and 2021.
- Compare monthly casualty trends across both years.
- Understand casualty distribution across different categories.
- Present key insights using KPIs, charts, and filters.

## Tools & Technologies
- Microsoft Excel 2016
- Pivot Tables and Pivot Charts
- Excel Formulas
- Data Analysis
- Data Visualization
- Dashboard Design

## Key Performance Indicators (KPIs)
- Total Casualties
- Fatal Casualties
- Serious Casualties
- Slight Casualties
- Car Casualties

## Dashboard Features
- **Monthly Trend Analysis:** Compare casualties between 2020 and 2021.
- **Vehicle Type Analysis:** Explore casualties across different vehicle categories.
- **Road Type Analysis:** Compare casualties by road type.
- **Area-wise Analysis:** Analyze casualties in rural and urban areas.
- **Light Condition Analysis:** Compare casualties under daylight and darkness conditions.
- **Road Surface Analysis:** Explore casualties across different road surface conditions.
- **Weather Condition Analysis:** Analyze casualties under different weather conditions.
- **Wind Condition Analysis:** Compare casualties across wind condition categories.
- **Interactive Filters:** Filter the dashboard using available accident date, weather, and other category filters.
